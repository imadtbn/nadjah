# إدراج الموارد التعليمية من DZExams — منصة النجاح

هذا المسار مخصص **للنسخ التعليمي غير التجاري فقط** بعد التحقق من حق إعادة استضافة كل ملف ومن سماح المصدر بتنزيله.

## الوضع الحالي

- `assets/data/dzexams-model-candidates.json`: بيانات 30 نموذجاً فردياً تم التحقق من رقم النموذج، نوعه، فصله، سنة نشره وحالة التصحيح كما ظهرت في قوائم DZExams. **ليست نسخ PDF**.
- `assets/data/dzexams-sources.json`: روابط أقسام المواد والفصول الأصلية، وهي فهارس وليست ملفات PDF.
- `scripts/dzexams-import-template.csv`: قالب للروابط الفردية الدقيقة؛ املأ صفاً مستقلاً لكل PDF بعد التحقق من مالكه وسماح تنزيله.
- `scripts/import-dzexams-pdfs.py`: برنامج لاستيراد الملفات الفردية، والتحقق من توقيع PDF والحجم، وتجنب التكرار بالبصمة SHA-256، واحترام robots.txt، وتسجيل المصدر الأصلي.

## التشغيل

بعد تثبيت `requests` وتعبئة القالب بروابط ملفات حقيقية:

```bash
python -m pip install requests
python scripts/import-dzexams-pdfs.py --manifest scripts/dzexams-import-template.csv
python scripts/import-dzexams-pdfs.py --manifest scripts/dzexams-import-template.csv --execute --confirm-noncommercial
```

الأمر الأول فحص فقط، والثاني يحمّل الموارد المتحقق من أذوناتها. لا تُنشَر بطاقات المعاينة والتنزيل على الموقع إلا **بعد** وجود الملفات فعلياً والتحقق من مساراتها.

ملفات الموارد الناتجة: `resources/dzexams/<cycle>/<level>/<subject-hash>/semester-<n>/<id>.pdf`، وفهرس الملفات المنسوخة: `assets/data/dzexams-imported.json`.

## تنبيهات حقوقية وتقنية

- صفحة FAQ في DZExams تسمح بالمشاركة لأغراض تعليمية غير تجارية، لكنها تنص أيضاً على أن **ليست كل الموارد قابلة للتنزيل**؛ والموارد تأتي جزئياً من مساهمات وناشرين خارجيين.
- منصة النجاح الحالية تحتوي على إعلانات؛ لا تفترض أن إعادة استضافة الملفات ضمن موقع إعلاني تجارية أو غير تجارية تلقائياً. احصل على تأكيد حقوق واضح أو افصل النشر غير التجاري فعلياً قبل نسخ ملفات تابعة لأصحاب آخرين.
- لا تستخدم روابط فصل واحد بوصفها روابط تحميل لعشرة ملفات. يجب أن يحمل كل صف رابط الصفحة الفردية ورابط PDF الفعلي.
- يجب الاحتفاظ باسم المصدر والمؤلف الأصلي إن كان معروفاً، وتمكين إزالة أي مورد بناءً على طلب صاحب الحق.

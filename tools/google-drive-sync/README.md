# ربط Google Drive بمكتبة منصة النجاح

هذا المجلد يحتوي على سكربت Google Apps Script الذي يفهرس ملفات PDF تلقائيًا من مجلد Drive ويعيد قائمة JSON/JSONP ليقرأها الموقع.

## 1) أنشئ هيكل Drive

أنشئ مجلدًا رئيسيًا باسم **مكتبة منصة النجاح**، ثم اتبع هذا الهيكل بدقة:

```
مكتبة منصة النجاح/
  الطور الابتدائي/
    السنة الثالثة/
      اللغة العربية/
        الفصل الأول/
          الدروس والملخصات/
          التمارين/
          الفروض والاختبارات/
          الحلول والتصحيحات/
        الفصل الثاني/
        الفصل الثالث/
  الطور المتوسط/
  الطور الثانوي/
```

كرّر مجلدات السنوات والمواد المناسبة لكل طور. يقبل السكربت أسماء الأطوار: الطور الابتدائي، الطور المتوسط، الطور الثانوي. ويقبل أسماء الفصول: الفصل الأول، الفصل الثاني، الفصل الثالث.

**مهم:** يقرأ السكربت ملفات PDF الموجودة داخل مجلدات نوع المورد مباشرة. لا تضع ملفات PDF في مجلد الفصل نفسه؛ ضعها داخل مجلد نوع المورد.

## 2) انشر السكربت

1. افتح https://script.google.com وأنشئ مشروعًا جديدًا.
2. انسخ محتوى `Code.gs` إلى محرر Apps Script.
3. افتح مجلد **مكتبة منصة النجاح** في Drive، وانسخ معرّف المجلد من عنوان الرابط. المعرّف هو النص الواقع بعد `/folders/`.
4. استبدل قيمة `ROOT_FOLDER_ID` في أول الملف بمعرّف المجلد.
5. من **Deploy → New deployment** اختر **Web app**.
6. اجعل **Execute as** = Me، و**Who has access** = Anyone، إذا كان هذا متاحًا لحسابك وتوافق على نشر بيانات الفهرس للعامة.
7. وافق على الأذونات، ثم انشر وانسخ رابط التطبيق الذي ينتهي بـ `/exec`.

لا تشارك رابطًا يحتوي على بيانات سرية. لا يحتوي هذا السكربت على مفاتيح API، ولا يغيّر صلاحيات ملفات Drive تلقائيًا.

## 3) صلاحيات ملفات PDF

حتى يستطيع الزائر معاينة الملف أو تحميله، افتح مشاركة الملف أو المجلد المناسب واضبط الوصول إلى **أي شخص لديه الرابط — مشاهد**، أو استخدم ملفات عامة تسمح بإعادة استخدامها. لا تجعل ملفات خاصة عامة دون مراجعة.

## 4) تحديث المكتبة

تُقرأ الملفات من Drive عند طلب الفهرس؛ لذلك فإن إضافة PDF إلى المجلد الصحيح تجعله يظهر في الفهرس دون تعديل JSON يدوي. قد يستغرق ظهور التغيير قليلًا بسبب التخزين المؤقت لدى المتصفح أو الاستضافة.

## 5) الربط النهائي بالموقع

بعد نشر التطبيق، نحتاج رابط `/exec` لإضافته إلى إعدادات موقع منصة النجاح وتفعيل الاستيراد التلقائي. هذا المستودع وحده لا يستطيع نشر تطبيق Apps Script نيابةً عنك أو معرفة معرّف مجلد Drive الخاص بك.

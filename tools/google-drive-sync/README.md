# إعداد مكتبة منصة النجاح على Google Drive

تم ضبط السكربت مسبقًا على مجلد Drive الذي أرسله صاحب المشروع:
`1MnYHPr6Qnd35YRQKN1P6QklAXb_bmiZA`

## إنشاء الهيكل تلقائيًا

1. افتح [Google Apps Script](https://script.google.com/) بحساب Google نفسه الذي يملك مجلد المكتبة أو لديه صلاحية التعديل عليه.
2. أنشئ مشروعًا جديدًا، وافتح ملف `Code.gs` الافتراضي.
3. انسخ كامل محتوى ملف [Code.gs في المستودع](https://github.com/imadtbn/nadjah/blob/main/tools/google-drive-sync/Code.gs) والصقه في المحرر.
4. احفظ المشروع باسم **مكتبة منصة النجاح**.
5. من قائمة اختيار الدوال، اختر `setupLibraryStructure` ثم اضغط **Run / تشغيل**.
6. وافق على أذونات الوصول إلى Google Drive عند الطلب.
7. انتظر حتى ينتهي التنفيذ. افتح مجلد Drive وأعد تحميل الصفحة للتحقق من ظهور المجلدات.

الدالة تنشئ المجلدات الناقصة فقط، ولا تحذف ملفاتك أو تغيّر أسماء المجلدات الموجودة. وهي لا ترفع ملفات PDF تلقائيًا؛ دورها إعداد المجلدات لتضع الملفات المناسبة فيها.

## الهيكل الذي ينشئه السكربت

```
مكتبة منصة النجاح/
├── الطور الابتدائي/
│   ├── السنة الأولى/ ... السنة الخامسة/
│   │   └── المادة/
│   │       ├── الفصل الأول/
│   │       ├── الفصل الثاني/
│   │       └── الفصل الثالث/
├── الطور المتوسط/
│   ├── السنة الأولى/ ... السنة الرابعة/
│   │   └── المادة/
│   │       └── الفصول الثلاثة/
└── الطور الثانوي/
    ├── السنة الأولى/
    │   ├── جذع مشترك علوم وتكنولوجيا/
    │   └── جذع مشترك آداب/
    ├── السنة الثانية/
    │   └── الشعبة/ المادة/ الفصول الثلاثة/
    └── السنة الثالثة/
        └── الشعبة/ المادة/ الفصول الثلاثة/
```

داخل كل فصل توجد المجلدات التالية:
- **الدروس والملخصات**
- **التمارين**
- **الفروض والاختبارات**
- **الحلول والتصحيحات**

قوائم المواد والشعب المدرجة هي هيكل تنظيمي أولي، ويجب مراجعتها مقابل البرنامج الرسمي المعتمد قبل اعتبارها قائمة نهائية شاملة.

## وضع ملفات PDF

ضع كل ملف داخل المجلد الذي يطابق طوره وسنته ومادته وفصله ونوعه. استخدم أسماء واضحة مثل:
`اختبار الفصل الأول مع التصحيح.pdf`

لكي يتمكن زوار الموقع من فتح الملف، اضبط مشاركة الملف أو المجلد حسب الحاجة إلى **أي شخص لديه الرابط — مشاهد**، ولا تنشر ملفات خاصة أو محمية بحقوق نشر لا تسمح بإعادة توزيعها.

## تفعيل الاستيراد التلقائي في الموقع

بعد إنشاء المجلدات:

1. في Apps Script اختر **Deploy → New deployment → Web app**.
2. اجعل **Execute as** = Me، و**Who has access** = Anyone إذا كان ذلك متاحًا ومناسبًا لنشر فهرس الملفات.
3. اضغط **Deploy** ووافق على الصلاحيات.
4. انسخ رابط تطبيق الويب الذي ينتهي بـ `/exec`.
5. افتح [إعداد اتصال Drive في المستودع](https://github.com/imadtbn/nadjah/blob/main/assets/js/google-drive-config.js) وضع الرابط في المتغير `NADJAH_DRIVE_FEED_URL`، ثم احفظ التعديل.

بعدها يفهرس الموقع ملفات PDF الموجودة في المجلدات المعتمدة عند طلب الفهرس. قد تتطلب تغييرات الموقع انتظار نشر GitHub Pages أو تحديث ذاكرة المتصفح. اختبر رابط `/exec` أولًا، وتأكد أن الاستجابة تتضمن `count` و`resources`.
